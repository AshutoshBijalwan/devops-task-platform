# DevOps Task Platform

A hands-on project for learning and applying Linux, networking,
Git/GitHub, Docker, Nginx, and CI/CD concepts.

## Current Architecture

Currently running:

- Python Flask application
- Linux development environment
- Git version control

## Application Endpoints

- `GET /` - Application homepage
- `GET /health` - Application health check

## Project Goals

The application will progressively be:

1. Run on Linux
2. Containerized with Docker
3. Connected to PostgreSQL
4. Placed behind Nginx
5. Managed with Docker Compose
6. Integrated with GitHub Actions
7. Deployed to a Linux server
